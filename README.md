**AgroGestor** é uma aplicação web moderna, formal e totalmente funcional desenvolvida para auxiliar produtores rurais, engenheiros agrônomos e consultores na avaliação de terras agrícolas. O sistema oferece testes interativos de aptidão da terra, classificação de solos e acesso a um relatório técnico com link direto para o ambiente de desenvolvimento Visual Studio Code.

## 🚜 Sobre o Projeto

O **AgroGestor** nasceu da necessidade de oferecer uma ferramenta simples, porém tecnicamente embasada, para diagnóstico rápido de propriedades rurais. Utilizando metodologias adaptadas da **EMBRAPA** e conceitos de pedologia, o sistema entrega:

- Diagnóstico do potencial agrícola da terra (IPA)
- Classificação textural do solo
- Recomendações de manejo personalizadas
- Interface limpa, responsiva e de alta usabilidade

---

## ⚙️ Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🔍 **Teste de Aptidão da Terra** | Calcula o Índice de Potencial Agrícola (IPA) com base em fertilidade, disponibilidade hídrica e topografia. |
| 🧪 **Classificação de Solo** | Classifica o solo em Argiloso, Textura Média, Arenoso ou Franco-Arenoso, além de sugerir manejo adequado. |
| 📄 **Relatório Técnico** | Exibe um documento formal com recomendações agrícolas e disponibiliza link externo para o Visual Studio Code. |
| 🧭 **Sistema de Abas** | Navegação fluida entre as três seções principais, sem recarregamento de página. |
| 📱 **Responsividade** | Layout adaptável a desktops, tablets e smartphones. |

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e acessível.
- **CSS3** — Estilização avançada com Flexbox, Grid, animações e design formal.
- **JavaScript (Vanilla)** — Lógica dos testes, manipulação do DOM e controle de abas.
- **Font Awesome 6** — Ícones para melhor experiência visual.
- **Google Fonts** — Fontes `Inter` e `Playfair Display` para elegância e legibilidade.
